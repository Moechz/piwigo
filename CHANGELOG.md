# Changelog

All notable user-visible changes to the Piwigo TOS application package.

## 16.4.0-1 — 2026-11-09

### Added
- First release. Piwigo (`linuxserver/piwigo:version-16.4.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8023 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/piwigodocker/`.
